# Реферальная программа — локальный прототип

Копия страницы TravelLine Extranet на настоящих компонентах Reactor. Основа меню взята из [LK_B2B](https://github.com/Polina-ko-dis/LK_B2B), содержание и состояния — из предоставленных макетов Figma и тестовой страницы.

Публичная версия: [GitHub Pages](https://polina-ko-dis.github.io/ref_program/#/ReferralProgram).

Исходники находятся в `main`, готовая сборка для GitHub Pages — в `gh-pages`. Для обновления сайта выполните `pnpm build:pages` в сети с доступом к зависимостям Reactor и опубликуйте содержимое `dist/` в корень `gh-pages` вместе с пустым файлом `.nojekyll`. В Settings → Pages выбран источник `gh-pages`, папка `/`.

## Карта гостя

В папке `guest-card/` лежит второй прототип — карта гостя. Публичная версия: [GitHub Pages](https://polina-ko-dis.github.io/ref_program/guest-card/#/GuestCard), локально — **http://127.0.0.1:4177/#/GuestCard** (`pnpm dev` в папке `guest-card/`).

Локальная карта гостя использует штатные `Table`, `DataWidgetLayout`, `Label`, действия модальных окон и компоненты `Scaffold`. Для автономного запуска лента собрана из `RibbonBackground`, `RibbonButtonBack` и `RibbonButtonUserMenuView`, без загрузки серверного меню пользователя. Выбор даты и ваучеров работает через полные `DatePicker` и `Select`; даты без времени хранятся и форматируются в UTC, остальные значения — через `@reactor/intl`.

Дополнительные пакеты `@reactor/table` `0.0.154` и `@reactor/scaffold-ui` `0.0.224` совместимы с Reactor `0.0.226`. Настройка `publicHoistPattern` в `guest-card/pnpm-workspace.yaml` делает транзитивные Fontsource-пакеты доступными Sass-импортам при установке через pnpm.

Ссылка «Приглашенные гости» в блоке «Накопления» открывает стандартный `SidebarWindow`: прогресс реферальной программы и один пример гостя с датой регистрации 24.11.2026 и вознаграждением «начислено 3 ночи». Панель закрывается крестиком, кнопкой «Закрыть» или Escape; фокус возвращается к ссылке. На узком экране данные гостей располагаются в одну колонку. Ссылки с ФИО пока показывают уведомление о демонстрационном переходе, без открытия другой карточки.

Для обновления сайта выполните `pnpm build:pages` в папке `guest-card/` и опубликуйте содержимое её `dist/` в папку `guest-card/` ветки `gh-pages`. Корень `gh-pages` при этом не трогайте — там живёт сборка реферальной программы.

## Открыть

Локальный адрес: **http://127.0.0.1:4175/#/ReferralProgram**.

Для повторного запуска дважды нажмите `start-local.cmd`. Нужен установленный Node.js либо встроенный Node.js Codex. Пока сервер запущен в Codex, повторно запускать его не нужно.

Из терминала с Node.js и pnpm:

```powershell
pnpm install
pnpm dev
```

При первой установке необходим доступ к внутренней сети TravelLine. Реестр настроен только в `.npmrc` проекта: `http://nuget.travelline.lan:8081/repository/npm-group/`. Пароли и токены не используются. Уже установленные зависимости и ресурсы позволяют запускать приложение без обращения к стенду.

## Что работает

- Начальный экран со скидками и вариант с баллами.
- Ваучеры, лимит первых регистраций, повышение уровня и зависимые поля начисления баллов.
- Проверка полей, локальное сохранение, перезагрузка, активация и деактивация.
- Предупреждение о несохранённых изменениях при действиях меню и закрытии страницы.
- Панель «Прототип» внизу: тип программы, тип накопления (деньги, ночи, деньги и ночи — меняет подпись настройки повышения), заполнение примера, сброс и скрытие панели. Скрытая панель открывается кнопкой с иконкой кода справа внизу.
- Плавающая кнопка «Что изменилось»: шесть комментариев к правкам по ревью Reactor. «Назад» и «Далее» прокручивают страницу к изменению и подсвечивают его экземпляры; комментарий содержит значения до/после и причину. «Свернуть» оставляет подсветку, а «Скрыть изменения», крестик или Escape закрывают режим. Подсветка не перехватывает клики и не сохраняется вместе с настройками формы. Комментарий к вводной карточке доступен, пока она показана.

Кнопка «Сохранить» хранит настройки только в localStorage этого браузера по ключу `referral-prototype-v1`. Данные на qatl.ru не меняются. Категории ваучеров демонстрационные; остальные разделы меню не реализованы. Параметр `?presentation=1` изначально сворачивает панель прототипа.

## Основные файлы

- `src/ReferralPage.jsx` — описание и карточки страницы.
- `src/RewardGroup.jsx` — повторно используемая группа наград.
- `src/Navigation.jsx` — адаптированная левая панель.
- `src/App.jsx` — оболочка, локальные действия и окна.
- `src/model.mjs` — проверка и хранение настроек.
- `src/styles.css` — раскладка и переменные Reactor.
- `src/ChangeReview.jsx`, `src/review.mjs`, `src/change-review.css` — режим комментариев, список исправлений и его оформление.

## Проверки

```powershell
pnpm test
pnpm build
```

Проект использует Reactor `0.0.226`, как LK_B2B. Выбор русской локали и словари компонентов подключены перед первым рендером. При сборке Vite может сообщить о размере основного пакета Reactor; сборка при этом завершается успешно.
