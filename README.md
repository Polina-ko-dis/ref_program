# Реферальная программа — локальный прототип

Копия страницы TravelLine Extranet на настоящих компонентах Reactor. Основа меню взята из [LK_B2B](https://github.com/Polina-ko-dis/LK_B2B), содержание и состояния — из предоставленных макетов Figma и тестовой страницы.

## Открыть

Локальный адрес: **http://127.0.0.1:4175/#/ReferralProgram**.

Для повторного запуска дважды нажмите `start-local.cmd`. Нужен установленный Node.js либо встроенный Node.js Codex. Пока сервер запущен в Codex, повторно запускать его не нужно.

Из терминала с Node.js и pnpm:

```powershell
pnpm install
pnpm dev
```

При первой установке необходим доступ к внутренней сети TravelLine. Реестр настроен только в `.npmrc` проекта: `http://nuget.travelline.lan:8081/repository/npm-group/`. Пароли и токены не используются. Уже установленные зависимости и ресурсы позволяют запускать приложение без обращения к стенду.

## Что работает

- Начальный экран со скидками и вариант с баллами.
- Ваучеры, лимит первых регистраций, повышение уровня и зависимые поля начисления баллов.
- Проверка полей, локальное сохранение, перезагрузка, активация и деактивация.
- Предупреждение о несохранённых изменениях при действиях меню и закрытии страницы.
- Панель «Прототип» внизу: тип программы, заполнение примера, сброс и скрытие панели. Скрытая панель открывается кнопкой с иконкой кода справа внизу.

Кнопка «Сохранить» хранит настройки только в localStorage этого браузера по ключу `referral-prototype-v1`. Данные на qatl.ru не меняются. Категории ваучеров демонстрационные; остальные разделы меню не реализованы. Параметр `?presentation=1` изначально сворачивает панель прототипа.

## Основные файлы

- `src/ReferralPage.jsx` — описание и карточки страницы.
- `src/RewardGroup.jsx` — повторно используемая группа наград.
- `src/Navigation.jsx` — адаптированная левая панель.
- `src/App.jsx` — оболочка, локальные действия и окна.
- `src/model.mjs` — проверка и хранение настроек.
- `src/styles.css` — раскладка и переменные Reactor.

## Проверки

```powershell
pnpm test
pnpm build
```

Проект использует Reactor `0.0.226`, как LK_B2B. Выбор русской локали и словари компонентов подключены перед первым рендером. При сборке Vite может сообщить о размере основного пакета Reactor; сборка при этом завершается успешно.
